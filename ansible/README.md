# Ansible

Configures what Terraform provisions, plus independently managed hosts:
Proxmox hosts, VMs, LXC containers, single board computers, and the K3s
cluster.

Playbooks stay thin and compose the reusable roles under `roles/`. The K3s
node inventory is generated by Terraform — do not hand-edit
`inventories/k3s-nodes.yml`.

- Cluster bring-up: `ANSIBLE_CONFIG=ansible/ansible.cfg ansible-playbook
  ansible/playbooks/k3s_cluster.yml`
- Secrets committed to this tree: [secrets/README.md](secrets/README.md)
- Editing rules and validation commands: [AGENTS.md](AGENTS.md)
- Cluster rebuild runbook: [../docs/kubernetes-bootstrap.md](../docs/kubernetes-bootstrap.md)
